# AGH Internship Projects

This repository contains internship projects:

1. **[Avatar Task](./Avatar%20Task)** — **AI Virtual Avatar Assistant (Steve)**
   * Realistic 3D Human Avatar with accurate lip-syncing.
   * Hands-free **"Steve"** wake-word automatic microphone activation.
   * Multilingual conversation & translation across 7 languages (English, Tamil, Hindi, Telugu, Malayalam, Kannada, Spanish).
   * FastAPI + Groq AI backend with multi-turn conversation memory.
   * React 19 + Three.js (@pixiv/three-vrm) frontend.

2. **[groq-chatbot](./groq-chatbot)** — Conversational Groq chatbot with vector store.

---

## Quick Start (Avatar Assistant)

Navigate to the `Avatar Task` directory:

```bash
cd "Avatar Task"
```

Double-click `start.bat` or run:

```powershell
.\start.ps1
```

* Frontend: http://localhost:5173
* Backend: http://127.0.0.1:8000
